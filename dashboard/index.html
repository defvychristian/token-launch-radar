How the value is scored

The implied value is the entry's own claim, computed from the snapshot alone. It does not predict whether or when a token is issued.

  1. Peer multiple. For each category, the median market-cap / TVL of the live-token protocols in that category (at least 3 peers, else the whole market's median), clamped to 0.03–1.00.
  2. Base. TVL × peer multiple.
  3. Growth. The 7-day TVL change, clamped to −60%…+120%, moves the value by half its size: multiplier = 1 + growth × 0.5.
  4. Maturity. How long the protocol has run with no token: 0.6 + min(age, 1095 days) / 1095 × 0.4. Unknown age counts as 365 days.
  5. Implied value. Base × growth multiplier × maturity multiplier. Rank 1 is the most valuable.

The watchlist is the floor, never the ceiling: 40 protocols at or above $50M TVL that record no token and are not a wrapped, staked or bridged product of one that trades. The board adds every other rankable pre-token protocol below the floor — the early finds. A protocol is called pre-token because its record shows no token, never because it has none.
